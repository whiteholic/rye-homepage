### P2 兼容性风险：兼容 mousedown 可覆写已有笔输入拖动，已修正

本次读回 `js/game-ui.js:165` 的 mousedown 只检查 button，没有检查是否已有 drag；`:155` 的 pointerdown 对 pen 输入仍建立数值 ID 与 pointer capture。按照浏览器 Pointer Events 的兼容鼠标事件序列，笔的 pointerdown 后可能紧接兼容 mousedown，后者会把 drag.id 覆写为 mouse。后续数值 ID 的 pointermove／pointerup 不再匹配，lostpointercapture 则可能在兼容 mouseup 前清掉 drag，导致位移、收起或接续 click 抑制失效。

建议 mousedown 在已有 drag 时直接返回，保留原来的 pointer 所有权；真正 mouse 的 pointerdown 已经跳过，因此不影响本轮实测鼠标路径。主线程随后已修正，本 reviewer 最后读回 `js/game-ui.js:166` 为 `if (event.button !== 0 || drag) return;`。本项代码问题关闭，实体笔／触控兼容性仍未实测。
