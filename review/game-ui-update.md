- `#menu` 为抽象黄蓝游戏主菜单：巨大裁切 RYE、字母头像异形裁切与错位底片、四个文字入口。悬停和键盘聚焦时菜单选择与图形联动；无具象天空、云、地平线或麦田风景。字母为占位，不假装用户头像。另一任务新增的 avatar-preview、本机人物图和相关文件保留，未自动接入主页面。
- 自我介绍改为开放段落；行动目录使用分岔／窗口／屋檐／铅笔／相交弧线，摘句取自现有正文，宽屏联动预览，窄屏直接可读。正文仍连续显示，保留既有五主题、小节、旧环境第二节地址和来源返回。
- 兴趣为分类索引与文字封面陈列。19／6／10／8 共 43 项按原顺序保留，无官方封面、推荐理由、评分、排名或空详情按钮。宽屏通过不同跨度与留白变化建立节奏，各作品使用相同文字权重，不指定代表作；手机减少列数、长名换行。
- 工具仍为真实整理状态。音乐退出旧六标签，`#music` 保留两类内容整理页；全局 48px 唱片无常驻外框机身、标题或歌词。名称和麦克风／琴键／禁用播放在展开时显示；没有音频、假播放进度或持续旋转。没有把助手候选名称当作用户定稿。
- 电脑正文 18px，手机 17px；目录 15px，返回文字 18px、40px 局部斜切标记和 28px 箭头、整条点击高至少 56px；全部主题 17px、至少 52px。保留原生焦点提示，程序聚焦的标题不加大外框。
- 栏目分层动效总长约 380ms，类别约 220ms；快切取消旧动画，无遮罩阻断交互，文章和历史返回不播放长栏目动画。手动开关和系统减少动态约束 CSS 与脚本。

## 独立审阅与修正

新独立 Agent `game_ui_review` 只读实现并写入 [独立报告](game-ui-independent.md)，没有参与实现或控制浏览器。发现并修正：番剧帧角选择器不匹配、矮屏展开层未按实际高度定位。随后补查鼠标／笔兼容事件，加入已有drag保护，避免兼容mousedown覆盖触控笔的pointerId；鼠标分支用独立mousedown与全局mousemove，修正浏览器中最初不能拖动的问题。捕获阶段抑制拖动完成后的误点击，实测跨导航不跳页。报告建议的收藏节奏和当前文档状态也已调整并读回。

## 局限

原生 Enter／空格激活在当前浏览器模拟中未得到有效确认，不列为通过项；原生链接／按钮语义保留，未为模拟器添加特例。实体触屏、笔输入、屏幕阅读器、无脚本回退和操作系统减少动态没有本轮端到端实测。系统减少动态只完成代码审阅，不能称为系统实测。没有真实音频，不能验证播放和跨页不断音。

一次批量浏览器检查超时导致连接恢复，未保留该批输出，因此不将丢失的批次结果作为验收依据；后续针对实际可见页面补查。未另称独立JavaScript命令行语法检查通过，以浏览器执行、无错误日志、内容比对及独立审阅为实际证据。
