# 制作过程记录

本目录随项目同步，保存设计提案、用户反馈与否定方向、内容审阅、验证记录，以及图像探索的提示词和处理方法。历史方案不代表当前目标；继续设计时先看根目录的 [DESIGN.md](../DESIGN.md)。

## 记录入口

- 本目录根层 Markdown：页面与内容验证、阅读结构提案、游戏界面视频观察。
- [人物风格探索](portrait-concepts-2026-11-20/README.md)：四种人物概念的提示词、用户反馈、拼图脚本和图片尺寸记录。
- [原照片滤镜](portrait-filters-2026-11-20/README.md)：本地滤镜处理脚本、失败方向和检查结果。
- [人物艺术化重绘](portrait-redraw-2026-11-20/README.md)：保留本人和原穿搭的提示词、拼图脚本与检查结果。
- [咖啡馆重绘](portrait-redraw-cafe-2026-11-20/README.md)：新参考照片的提示词和成功、失败状态。
- [麦田蓝天参考图](visuals/2026-11-20-wheat-sky/README.md)：无人物的历史概念图与提示词；此方向已被否定。

## 公开与本机范围

过程文档、提示词、处理脚本、检查结果和无人物风景参考图可公开同步。人物原照片、含原照的对比图、人物衍生图片继续保留本机，由 `.gitignore` 排除。原照片引用使用 `private-inputs/` 占位路径，不保留剪贴板临时路径。

JSON 只记录模型、提示词与结果，不包含接口凭据，不能当成可直接重放的请求。历史检查结果说明当时的验证，不表示本次重跑了生成或图片处理。脚本的 Pillow、NumPy 仅用于离线制图，网页本身仍无依赖。

本目录不归档原始聊天、账号认证状态、凭据或公司资料。补充记录上传不代表将人物素材接入网页，也不代表页面或设计已定稿。
