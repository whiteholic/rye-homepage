# 兴趣页：去方框、圆环聚合与轻浮动

日期：2026-11-22。用户明确不希望兴趣页使用方框，并提出共同圆圈和浮动。此次按这一方向在两个实际入口进行局部样式更新，保留已有内容、分类、头像与阅读系统。

## 取舍与实现

每部作品改成小圆会让长书名挤压或保留卡片感；让作品沿圆周旋转会使扫读和手机显示困难。因此采用一个共同椭圆包围当前类别的完整清单，名称水平、自然换行，只有小幅上下浮动。类别保持一次查看一类，未把 43 条同时堆到同一圆圈。

- 去掉单项渐变底板、方角、电影票边和书脊，四个类别共用无底板文字样式。
- 一个钴蓝椭圆和少量金色装饰聚合作品，保持字号一致、不暗示排名。原类别含义、作品顺序和真实清单不变。
- 浮动使用独立 translate，9／11／13 秒不同周期与负延迟，电脑正负 5px、手机正负 3px。浮动不影响正常排版位置；留白大于浮动范围。
- 鼠标进入作品区暂停，隐藏类别与非活动栏目暂停。现有动效关闭和系统减少动态规则继续生效，OFF 后动画名为 none、translate 为 none。
- 手机纵向延展圆环，作品自然换行，长名保留完整。不加入拖拽、点击详情或自动轮播。

## 实际检查

主线程使用浏览器技能检查实际页面；这是局部 CSS 更新，按比例自检，未另调用独立 Agent。

- 宽屏 1280×900：查看实际圆环与 19 个作品名；读取到不同名称的 translate 分别约为 -4.91／-0.18／-1.45px，确认错时浮动在运行。
- 手机 320×844：查看推荐书，长书名完整，单项背景为 none。番剧 19 个条目的当前边界逐对比较没有重叠，整页无横向溢出。OFF 后浮动停止。
- 手机 392×844：依次切换游戏、电影、书、番剧，显示 6／10／8／19 项，各类均无整页横向溢出，地址保持 `#life`，错误日志为空。
- 四类数量仍为 19／6／10／8，类别按钮与原生清单语义保留；没有修改路由脚本和视觉脚本。
- 新样式资源标记 `interest-orbit-20261122`，两个入口同步引用同一 CSS。最终页面为 `/design-v2.html?v=interest-orbit-20261122#life`。

浏览器视口模拟不等于实体手机测试；未改变系统减少动态设置，相关规则沿用既有实现。没有重新遍历全文阅读系统，因正文、地址和脚本均未改。作品不会变成可点击卡片，也没有添加封面、推荐理由或音乐。
