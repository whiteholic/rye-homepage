| 位置或操作 | 拟采用的具体形式 |
| --- | --- |
| 栏目入口 | 顶部菜单“行动与思考”打开五个主题的目录，仅展示编号、现有主题标题与一行说明；说明取自现有正文，不补造经历。采用分隔线与文字行列，沿用黄蓝、斜切编号，避免五张相同方卡片。 |
| 首页关键词 | 仍直接打开相应主题，例如认知、环境；不强制经过主题目录。 |
| 单主题文章 | 一次只呈现一个主题正文。认知结尾不再紧接环境、房子等全文；文末以可选文字链接前往其他主题。 |
| 电脑认知页 | 左侧为轻量固定小节目录，右侧正文；正文最大宽度约 680px、字号 17px、行高约 1.9。五节可连续阅读，也可点击跳读，滚动时标明当前节。 |
| 手机认知页 | 单栏正文，左右留白约 20px、字号 16px、行高约 1.9。标题下放默认收起的“本篇目录 · 5 节”，展开后点小节即定位并收起；不把全站目录和文章目录同时展开在正文前。 |
| 五节名称 | 拥抱不确定性、成长型思维、主体思维、行动引领思考、向有成果的人学习。导航用短名，正文保留完整原标题与段落。 |
| 文章顶部 | 以简短路径标明“行动与思考 / 认知”，提供“返回刚才的位置”及“浏览全部主题”两个含义不同的入口。直接用链接打开且没有站内来源时，只显示“浏览全部主题”。 |
| 返回与后退 | 从首页进入则回到首页来源；从主题目录进入则回到目录位置；跨主题后退恢复上一文章的位置与来源焦点。小节跳读记入地址，单纯滚动不增加后退次数。 |
| 地址与兼容 | 保留现有五主题地址及 `#action/environment-experience`；认知五节增加独立定位地址。刷新保留主题和指定小节，失效的小节回到该主题开头，失效主题回到目录。 |
| 核对范围 | 同步两版阅读结构，首页构图各自保留。验收 320／390／430／768／1280px 的换行、触控、键盘目录、当前小节标记、刷新及返回；检查无脚本时所有正文仍可阅读。正文逐段一致，其他栏目无行为回退。 |

这一方案解决不同主题混排和文章内定位，认知全文的总长度不会变短。折叠所有小节需要反复展开，不能稳定解决长文阅读；一次只显示一节能进一步减少当屏内容，但会增加切换、影响通读与对照。用户已确认采用上表的连续阅读加目录，没有加入章节切换、轮播或滑动翻页。提案形成时只更新本地说明；确认后已更新两版 HTML、共享样式与脚本，并修正第二版阅读区文字链接颜色。未修改原稿或个人上下文，未提交、上传、发布。
