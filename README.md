# 李佳润 · Rye 个人主页

纯静态单页，无构建、无依赖。内容按页签分块，每个页签只显示一个模块，避免单页过长。用浏览器直接打开 `index.html` 即可预览。

定位、红线、写作原则和已确认内容的决策过程记录在 [DESIGN.md](./DESIGN.md)，换电脑继续设计前先读它。

## 本地预览

直接双击 `index.html`，或在 `site/` 目录下起一个静态服务：

```powershell
python -m http.server 8000
```

然后访问 http://localhost:8000 。

## 结构

- `index.html`：页面结构、页签与文案
- `css/style.css`：样式，页签导航在顶部居中
- `js/main.js`：页签切换、地址栏 hash 同步、年份自动更新

四个页签：关于我 / 行动与思考 / 兴趣 / 工具与分享。切换时用 `#` 后的 hash 记录当前页签，刷新或分享链接会停留在对应页签。

## 已填充

- 名字：李佳润，英文名 Rye
- 关于我：自我介绍按金字塔原则写成，并合并了最近四个月的社交经历、MBTI 的看法、Know Yourself，末尾是明确的联系引导

## 发布前要替换的内容

1. 联系方式：`index.html` 里 `mailto:your-email@example.com` 换成真实邮箱；以后想用表单，再接入 Formspree 之类服务。
2. 兴趣页签：`工作之外` 目前是示例内容，换成真实的电影、番剧、周末活动和爱好，并删掉那句“以下为示例”。
3. `行动与思考` 页签：现在是按定位写的第一稿，发布前用真实细节替换或微调。
4. `工具与分享` 页签：目前是三条占位示例，替换成你收藏的网站和文章，附上推荐理由。
5. `meta description` 和 `<title>` 已带名字，按需补充。

## 发布

三种方式任选其一，站点根目录都指向 `site/`：

- GitHub Pages：仓库里把 Pages 的源设为 `site/` 目录，或走 Actions 部署。
- Cloudflare Pages：构建命令留空，输出目录填 `site`。
- Vercel：Framework Preset 选 Other，Root Directory 填 `site`。
