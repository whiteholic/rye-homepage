## 本地预览

直接双击 `index.html`。若已安装 Python，也可在本仓库根目录（与 `index.html` 同级）启动静态服务：

```powershell
python -m http.server 8000
```

然后访问 [本地预览](http://localhost:8000)。当前仓库没有 `site/` 子目录。

第二版直接打开 `design-v2.html`，或访问同一服务下的 `/design-v2.html`。本次设计任务的本机预览使用 [8018 端口](http://127.0.0.1:8018/design-v2.html)，只在对应本地服务运行期间可访问。
